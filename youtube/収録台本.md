# 収録台本・録画手順

---

## 1. 録画の準備（共通）

### 使うもの
Windows 11 標準の **Xbox Game Bar** だけで足ります。追加ソフトは不要です。

### 事前設定（1回だけ）
1. `Win` + `I` → **ゲーム** → **キャプチャ**
2. 「録画するビデオのフレームレート」→ **60 fps**
3. 「ビデオの品質」→ **高**
4. 「録音するオーディオ」→ **すべて** または **ゲーム**（ゲームの効果音を拾うため）
5. マイクは基本 **オフ**（あとから声を入れる場合のみオン）

### 録画のしかた
1. ブラウザーで対象ページを開く
2. `F11` で全画面表示にする
3. `Win` + `Alt` + `R` で録画開始（右上に録画インジケーターが出ます）
4. もう一度 `Win` + `Alt` + `R` で停止
5. 保存先：`C:\Users\user\Videos\Captures\`

> **コツ**：録画開始直後の2〜3秒は無音・無操作にしておくと、編集で切りやすくなります。

## 2. 通常動画（横・目標3分40秒）

### 録画するページ

| 場面 | 開くURL |
|---|---|
| デモ（AIの自動プレイ） | `index.html?demo=1&rec=1` |
| 自分でプレイ | `index.html?rec=1` |

`rec=1` を付けると画面下のヒント文やタッチボタンが消え、ゲーム画面が最大化されます。

### 構成

| 時間 | 内容 | 撮り方・話すこと |
|---|---|---|
| 0:00〜0:20 | **オープニング** | `?demo=1&rec=1` のデモ画面から。インベーダーが撃ち落とされる場面をいきなり見せる。「ブラウザーだけで遊べるインベーダーゲームを作りました」 |
| 0:20〜0:45 | **どんなゲーム？** | 画面全体を見せながら。「インストール不要、登録不要。URLを開くだけ。PCでもスマホでも動きます」 |
| 0:45〜1:15 | **操作方法** | 実際に左右に動かし、1発撃つ。「移動は左右キー、発射はスペース。スマホは画面下のボタンです」 |
| 1:15〜2:00 | **レベル1をプレイ** | `?rec=1` で自分でプレイ。淡々と削っていく。「残りが少なくなると動きが速くなります」 |
| 2:00〜2:30 | **UFOボーナス** | ピンクのUFOが出るのを待って撃つ。**得点表示が出た瞬間がハイライト**。「50点から300点、当たると美味しいです」 |
| 2:30〜3:00 | **シールドの使いどころ** | わざとシールドに撃ち込んで削れる様子を見せる。「盾ですが、自分の弾でも削れます。撃つ場所を選ぶのがコツ」 |
| 3:00〜3:40 | **レベルが上がると** | レベルクリア演出 → レベル2の速さを見せる。「レベルが上がるほど速く、爆弾も増えます」 |
| 3:40〜 | **まとめ** | タイトル画面かゲームオーバー画面で締め。「概要欄のURLから今すぐ遊べます。ハイスコアをコメントで教えてください」 |

### 素材が足りないとき
`?demo=1&rec=1` を5〜10分ほど回しっぱなしにして録画しておくと、UFO撃破・ギリギリの回避・レベルクリアが自然に出てきます。あとから必要な部分だけ切り出せます。

## 3. ショート動画（縦・60秒）

### 録画するページ

`shorts.html` を開く → `H` キーで右下の操作パネルを隠す → `F11` で全画面 → `Win` + `Alt` + `R`

このページは 1080×1920 の縦フレームで、上にタイトル、中央にゲーム画面（自動デモ）、下にURL帯が入っています。**そのまま録画すれば縦動画になります。**

> `R` キーでゲームを最初からやり直せます。良い展開が出るまで何度か回してください。

### 構成（60秒）

| 時間 | 内容 |
|---|---|
| 0:00〜0:03 | **つかみ**：いきなり撃ち合っている場面から。テロップ「ブラウザーだけで遊べる」 |
| 0:03〜0:10 | タイトルとURL帯を見せる。テロップ「インストール不要・無料」 |
| 0:10〜0:25 | インベーダーを次々撃ち落とす場面 |
| 0:25〜0:40 | **UFO撃破**（得点表示が出る瞬間）を入れる |
| 0:40〜0:52 | シールドが削れる／ギリギリで爆弾を避ける場面 |
| 0:52〜1:00 | 下部URL帯にズーム。テロップ「概要欄のリンクから今すぐ」 |

### ショートの注意点
- **最初の1秒が勝負**です。タイトル画面から始めず、必ず動いている場面から始めてください
- 縦動画は下部20%程度にYouTubeのUI（いいね・コメント等）が重なります。`shorts.html` のURL帯はやや上に配置してありますが、編集で確認してください
- 尺は **60秒未満**（59秒以下）にしてください

## 4. 編集について

凝った編集は不要です。無料でできる範囲だと：

- **Windows 標準「Clipchamp」**：前後のカット、テロップ入れ、書き出しまで可能。まずはこれで十分です
- やることは3つだけ
  1. 前後の不要部分をカット
  2. 冒頭にテロップ（「ブラウザーで無料」など）
  3. 1080p / 60fps（ショートは 1080×1920）で書き出し

---

## 5. アップロード手順

1. YouTube Studio →「作成」→「動画をアップロード」
2. タイトル・概要欄は [概要欄.md](概要欄.md) からコピー
3. サムネイル：`thumbnail-wide.png` を選択（通常動画のみ）
4. 「子ども向けではない」を選択
5. 公開設定：まず **限定公開** で自分のスマホから確認 → 問題なければ **公開**
6. 公開後：終了画面・カード・固定コメントを設定（[概要欄.md](概要欄.md) の「投稿後にやること」参照）

## 6. 収録前チェックリスト

- [ ] **録画を始める前にゲーム画面を1回クリックしたか**（ブラウザーの仕様上、一度クリックしないと効果音が鳴りません。録画モードではクリックしてもデモは止まりません）
- [ ] ブラウザーの通知・拡張機能のバッジが画面に写り込まないか
- [ ] 音量は適切か（`M` キーでミュートしていないか）
- [ ] `?rec=1` を付けて周辺UIを消したか
- [ ] `shorts.html` は `H` キーで操作パネルを隠したか
- [ ] 画面解像度は 1920×1080 か（Win + I → システム → ディスプレイ）
- [ ] デスクトップの他のウィンドウが写り込まないか（F11の全画面で解決）

# 動画の作り方

**録画ソフトも編集ソフトも要りません。ボタンを1回押すだけです。**

---

## 1. 手順（これだけ）

### ① このページを開く

**https://yhdog0425-eng.github.io/retro-invaders-84/movie.html**

> ⚠️ パソコン内の `movie.html` をダブルクリックして開いた場合は録画できません。ブラウザーの安全機能でゲーム画面を読み取れないためです。**必ず上のURLから開いてください。**
>
> ブラウザーは **Chrome か Edge** を使ってください。

### ② 形式を選ぶ

| ボタン | 用途 | 長さ |
|---|---|---|
| 通常動画 1280×720 | YouTubeの普通の動画 | 2分30秒 |
| ショート 1080×1920 | YouTubeショート | 55秒 |

### ③ 画面のどこかを1回クリックする

これをしないと**音が入りません**。ブラウザーの仕様で、一度クリックするまで音を鳴らせない決まりになっています。

### ④「まずテスト録画（15秒）」を押す

15秒だけ録画して、ダウンロードフォルダーにファイルが保存されるか確かめます。**最初は必ずこれを試してください。**

### ⑤「本番の録画をはじめる」を押す

- 選んだ長さのぶん、**実際に再生しながら録画**します（通常動画なら2分30秒かかります）
- 終わると `retro-invaders-84.webm` が自動でダウンロードフォルダーに保存されます
- そのまま YouTube にアップロードできます

> **録画中はこのタブを最前面に置いたままにしてください。** 他のタブや他のアプリに切り替えると、ブラウザーが画面の更新を止めてしまい、映像が飛びます。2分30秒のあいだ、席を立って待つのがおすすめです。

## 2. 出来上がる動画の中身

テロップまで焼き込み済みなので、**編集は不要**です。

### 通常動画（2分30秒・1280×720）

左にゲーム画面、右にタイトル・スコア・URLが出るレイアウトです。

| 時間 | 内容 |
|---|---|
| 0:00 | タイトル「レトロインベーダー84 ／ ブラウザーで、あの頃へ。」 |
| 0:06 | 「1978年、駄菓子屋の店先に、その筐体はあった。」 |
| 0:14 | 「移動は ← →」「発射は スペース」 |
| 0:30 | プレイのみ（音を聴かせる区間） |
| 1:10 | 「ピンクのUFOは 50〜300点」 |
| 1:25 | 「シールドは、自分の弾でも削れる」 |
| 1:55 | 「レベルが上がるほど、速くなる」 |
| 2:15 | URLカード「今すぐ、無料であそべます」 |

UFOが画面に出たときは、自動で「UFO 出現！」のテロップが入ります。

### ショート（55秒・1080×1920）

上にタイトル、中央にゲーム画面、下にURL帯。**下部はYouTubeのボタンが重なる領域を避けて余白を取ってあります。**

| 時間 | 内容 |
|---|---|
| 0:00 | 「ブラウザーだけで遊べる」 |
| 0:03 | タイトル |
| 0:08 | プレイ |
| 0:22 | 「UFOは 50〜300点」 |
| 0:32 | プレイ |
| 0:45 | URLカード |

## 3. アップロード手順

1. YouTube Studio →「作成」→「動画をアップロード」→ 保存された `.webm` を選ぶ
   - **WebM形式はYouTubeがそのまま受け付けます。変換は不要です**
2. タイトル・概要欄は [概要欄.md](概要欄.md) からコピー
3. サムネイル：`youtube\thumbnail-wide.png` を選択（通常動画のみ。ショートは1コマ目が使われます）
4. 「子ども向けではない」を選択
5. まず **限定公開** にして自分のスマホで確認 → 問題なければ **公開**
6. 公開後：終了画面・カード・固定コメントを設定（[概要欄.md](概要欄.md) の「投稿後にやること」参照）

## 4. よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| ボタンを押しても何も起きない | `file://` で開いている。公開URLの `movie.html` を開き直す |
| 「このブラウザーは録画に対応していません」 | Chrome か Edge で開く |
| 音が入っていない | 録画を始める前に、画面のどこかを1回クリックする |
| 映像がカクつく・飛ぶ | 録画中に別のタブやアプリへ切り替えた。タブを最前面のままにして録り直す |
| ファイルが見つからない | `C:\Users\user\Downloads\` を確認。ブラウザー右上のダウンロード一覧からも開ける |

## 5. 自分でプレイしたところを撮りたい場合（任意）

自動生成ではなく、自分の腕前を見せたいときは従来どおり画面録画もできます。

1. `https://yhdog0425-eng.github.io/retro-invaders-84/index.html?rec=1` を開く（周辺のUIが消えます）
2. 画面を1回クリックして音を有効化
3. `F11` で全画面 → `Win` + `Alt` + `R` で録画開始（Xbox Game Bar）
4. もう一度 `Win` + `Alt` + `R` で停止。保存先は `C:\Users\user\Videos\Captures\`
5. 編集が必要なら Windows 標準の **Clipchamp** で前後をカット

事前設定：`Win` + `I` →「ゲーム」→「キャプチャ」→ フレームレート **60fps**、品質 **高**、録音するオーディオ **すべて**

## 6. 参考：URLパラメーター

| URL | 動作 |
|---|---|
| `index.html?demo=1` | CPUの自動プレイ |
| `index.html?rec=1` | 周辺UIを消して画面を最大化 |
| `index.html?crt=0` | ブラウン管の走査線表示をオフ（ゲーム中は `C` キーでも切替） |
| `movie.html` | 動画の自動生成 |
| `shorts.html` | 縦フレーム表示（自分で画面録画する場合用） |

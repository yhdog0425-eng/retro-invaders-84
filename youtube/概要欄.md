# YouTube 投稿用テキスト一式

そのままコピー＆ペーストして使えます。`【要編集】` の箇所だけご自身の情報に置き換えてください。

---

## ■ 通常動画（横・3〜5分）

### タイトル案（1つ選ぶ）

1. `【ブラウザーで無料】自作インベーダーゲーム「レトロインベーダー84」を遊んでみた`
2. `インストール不要！ブラウザーだけで遊べるレトロシューティングを作りました`
3. `【個人開発】HTML1ファイルで作ったインベーダーゲーム｜レトロインベーダー84`

> タイトルは全角32文字くらいまでがスマホで省略されずに表示されます。1案が最も無難です。

### 概要欄（このブロックをそのまま貼り付け）

```
▼ 今すぐ遊べます（無料・インストール不要・登録不要）
https://yhdog0425-eng.github.io/retro-invaders-84/

80年代アーケード風のドットシューティング「レトロインベーダー84」を作りました。
ブラウザーを開くだけで、PCでもスマホでもすぐに遊べます。


■ 操作方法
【PC】
　移動：← →（A / D でもOK）
　発射：スペースキー
　一時停止：P ／ 音のON・OFF：M
【スマホ・タブレット】
　画面下の ◀ ▶ ボタンで移動、「撃つ」ボタンで発射


■ ルール
・インベーダーを全滅させると次のレベルへ
・残りが減るほどインベーダーの動きが速くなります
・得点は種類ごとに 10点 / 20点 / 30点
・ときどき現れるピンクのUFOは 50〜300点のボーナス
・緑のシールドは盾になりますが、自分の弾でも削れます
・インベーダーが地上に到達したらゲームオーバー（残機3機）
・ハイスコアはブラウザーに自動保存されます


■ 目次
0:00 オープニング
0:20 どんなゲーム？
0:45 操作方法
1:15 実際にプレイ（レベル1）
2:00 UFOボーナスを狙う
2:30 シールドの使いどころ
3:00 レベルが上がると…
3:40 まとめ・遊び方


■ 技術的なこと
・HTML 1ファイルだけで動きます（ビルド不要・ライブラリ不使用）
・描画は Canvas 2D、ドット絵は自作
・効果音は Web Audio API でその場で合成しているので、音声ファイルは1つも使っていません
・外部への通信は一切なし。保存するのはハイスコアだけです

ソースコード（MITライセンス・自由に改造できます）
https://github.com/yhdog0425-eng/retro-invaders-84


■ ご注意
本作はクラシックアーケードゲームにインスパイアされた完全オリジナル作品です。
ドット絵・効果音・プログラムはすべて新規に制作しており、既存商用ゲームの素材は使用していません。
「スペースインベーダー」は株式会社タイトーの登録商標であり、本作とは関係ありません。


#レトロゲーム #個人開発 #ブラウザゲーム #インベーダー #JavaScript
```

## ■ ショート動画（縦・60秒）

### タイトル案

1. `ブラウザーだけで遊べるインベーダー作った #Shorts`
2. `インストール不要のレトロシューティング #Shorts`
3. `HTML1ファイルでインベーダーゲーム作ってみた #Shorts`

> タイトルか概要欄に `#Shorts` を必ず入れてください（ショート棚に載りやすくなります）。

### 概要欄（短く。冒頭にURLを置くのがコツ）

```
▼無料で遊べます（インストール不要）
https://yhdog0425-eng.github.io/retro-invaders-84/

HTML1ファイルだけで作ったレトロシューティング。
PCもスマホもブラウザーを開くだけ。

#Shorts #レトロゲーム #個人開発 #ブラウザゲーム #ゲーム制作
```

## ■ 投稿後にやること

1. **サムネイル設定**：`thumbnail-wide.png` をアップロード（通常動画のみ。ショートは1コマ目が使われます）
2. **終了画面**：動画の最後5〜20秒に「リンク」要素を置き、プレイページURLを指定
3. **カード**：1:15 あたりに情報カードでプレイページURLを差し込む
4. **固定コメント**：自分でコメントを書いて固定する
   ```
   ▼ここから遊べます（無料・インストール不要）
   https://yhdog0425-eng.github.io/retro-invaders-84/
   感想やハイスコア、ぜひコメントで教えてください！
   ```
5. **再生リスト**：「自作ゲーム」などの再生リストを作って通常動画とショートをまとめる

## ■ BGMについて

このゲームの効果音は自前で合成しているため権利上クリアです。BGMを足す場合は、必ず
**YouTube オーディオ ライブラリ**（YouTube Studio →「オーディオ ライブラリ」）の楽曲など、
利用が許諾されている音源を使ってください。市販曲を使うと収益化停止やブロックの対象になります。

無音でも成立する構成にしてあるので、BGMなしで投稿しても問題ありません。
